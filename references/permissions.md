# 部署文件权限与验收

新建、更新应用或安装技能工具时使用本节；不依赖是否启用凭据库。只处理本次部署涉及的路径，不顺带修改其他应用、账号或系统目录。

## 确定读写范围

部署账号负责更新代码，运行账号读取代码并写入核实后的业务数据、上传、缓存或日志目录。代码、依赖、启动器和服务配置由受信任的部署账号管理，不能因归运行账号所有、组写权限、ACL、符号链接或上层目录可替换而失去保护。仅移除文件写位不足以限制文件所有者。

沿用既有数据位置，明确列出可写目录；位于代码树内的数据目录也要单独保护，不能对整棵项目目录递归 chown 给应用账号，或为了方便而统一开放写权限。应用确需生成插件或其他可执行内容时，按项目适配规则核实并记录具体范围及信任边界，不把整棵代码树当作数据目录。

上传或解包后的权限以目标 Linux 上的结果为准，不沿用 Windows 打包产生的权限。按实际文件角色设置属主、组和模式，保留所需执行位及受信任的链接；不要对包含业务数据、挂载点或凭据的未知目录整体 chmod/chown。

## 安装技能工具

从已核实的技能源目录安装到稳定路径。先确认目标目录及其上层由受信任管理员控制，不能被应用账号替换；root 管理布局的示例如下。`skill_dir` 是可信源目录，不是任意上传目录。

```bash
sudo install -d -m 0755 /usr/local/lib/server-port-deploy/scripts /usr/local/lib/server-port-deploy/references
sudo install -m 0644 "$skill_dir"/scripts/*.py /usr/local/lib/server-port-deploy/scripts/
sudo install -m 0644 "$skill_dir"/references/server-deployments-template.md /usr/local/lib/server-port-deploy/references/
```

脚本和模板一起安装、检查；解包到目标目录本身不代表安装完成。不需要第三方凭据时，到此即可，不创建凭据库或 identity。启用凭据时再按 [凭据存储与接入](credentials.md) 初始化与绑定。

## 每次部署后验收

在登记成功前，核对实际服务进程的 UID/GID、附加组和读写范围；以应用账号检查本次代码、依赖、技能工具（包括模板）、启动器、unit 及其配置依赖。不能用 root 下的访问测试代替应用账号的权限。

普通 Linux 主机可使用只读检查工具。路径按本次实际部署替换；可重复传入 `--read-only` 与 `--writable`，并包含代码树外的启动配置和依赖：

```bash
sudo runuser -u "$app_user" -- python3 /usr/local/lib/server-port-deploy/scripts/check_permissions.py \
  --expected-user "$app_user" \
  --read-only "$app_dir" \
  --read-only /usr/local/lib/server-port-deploy \
  --read-only /etc/systemd/system/example.service \
  --writable "$data_dir"
```

工具递归检查可读取的只读范围，跟踪链接并检查上层目录是否允许替换，使用当前账号的实际访问检查（含组与 ACL），同时发现运行账号拥有只读文件的问题。只排除显式列出的数据/缓存子树；检查不会写文件、读取文件内容或修改权限。退出码 0 表示列出的检查通过，1 表示发现问题，2 表示平台、身份或参数不适用。路径不存在、无法遍历或链接无法解析均不能算通过；指向已检查目录的链接不重复遍历。

检查范围由调用者提供；它不自动发现遗漏的 unit、环境文件或进程，也不验证数据目录里每个已有文件的可写性。数据目录的权限检查通过后，仍需通过实际最小业务操作确认能写入所需文件。凭据启动器有只允许 root 读取的配置时，保持原有保护，按 [凭据验证](credentials.md#存储边界) 做访问拒绝测试，不为通过可读性检查而开放秘密。

容器、用户命名空间、附加组覆盖或 systemd 只读挂载可能改变服务实际可见的权限；在对应环境中做等价检查，并分别记录宿主机文件权限与服务沙箱限制。不能把 `runuser` 的检查直接说成线上进程已经拥有相同访问能力，也不能仅凭沙箱配置忽略宿主机上的可写部署脚本或模板。

失败时先定位具体路径，仅修正已授权的部署范围并复验；涉及未明确的数据、挂载或应用特殊要求时按适配规则处理。登记运行身份、检查范围、结果和实际限制，未完成权限与业务验证不能登记为部署成功。
